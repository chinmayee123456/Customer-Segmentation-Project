# Customer Segmentation Project

## Objective
This project segments customers based on annual income and spending behavior using K-Means clustering.

## Tools Used
- Python
- pandas
- matplotlib
- scikit-learn
- VS Code

## Dataset
Mall Customers Dataset from Kaggle.

## Features
- Data preprocessing
- Elbow Method
- K-Means clustering
- Customer segmentation visualization

## Output
Customers are grouped into different clusters based on purchasing patterns and spending scores.

## How to Run

1. Install required libraries:
pip install pandas matplotlib scikit-learn

2. Run the project:
python app.py
